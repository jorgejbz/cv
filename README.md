## Cómo está hecho
HTML, CSS y JavaScript sin frameworks. Todo el texto, en español e inglés, está en `js/lang.js`.
El botón **Descargar PDF** usa la impresión del navegador ("Guardar como PDF"), así que el PDF sale con texto real
que pueden leer los sistemas de reclutamiento (ATS). El diseño de impresión está en `@media print` de `css/styles.css` (A4, 2 páginas).
